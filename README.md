# かいものスキャン v0.6.1

Android用のバーコード買い物計算アプリ。セブン公式の商品ページとJANコードを初回にひも付け、次回から掲載価格を取得して税込の概算合計を計算します。Yahoo!からのメーカー希望小売価格取得と手入力も使えます。

3番の「レシート＋チェック」をアプリアイコンとして採用。GitHubへのアップロード方法は [GITHUB_UPLOAD.md](GITHUB_UPLOAD.md) を参照してください。

## 端末に合わせたダークモード

端末のダークテーマ設定に合わせて自動で切り替わります。Androidの設定で外観を変更し、アプリを表示してください。対応するOSでのスケジュール切り替えにも追従します。アプリ独自の時刻指定や手動切り替えはありません。

- ライト：白背景・黒文字・インディゴのメインボタン。
- ダーク：#202020のチャコール背景、白文字、#9D9D9Dの補助文字、#F45500のスキャンボタンと柔らかなオレンジの発光。
- ダークの補助操作・リンク：#9E9EFF。カード・ボタン・入力欄は20dpの角丸。カードは細い枠で区別し、影は付けません。
- 大きな金額は細字。説明文はシステムserif、操作と見出しはsans-serif。GT-FlexaやTimesの独自フォントは同梱せずOSフォントを利用します。
- オレンジボタンの文字は、添付資料の黒文字の例に合わせ、読みやすい黒を採用しています。

システムのテーマ変更時はAndroidが画面を再作成します。保存済みの買い物一覧・残高・設定と、表示中だった連続スキャン画面を復元します。入力途中のダイアログは閉じるため、テーマ変更前に入力を保存してください。見た目の実機検証は未実施です。

## 白とインディゴのデザイン

添付のスタイルリファレンスに合わせ、白背景・黒文字・補助文字#595959、主要ボタンのみ#4D49FCを使用。メインのスキャンボタンは画面下部に固定し、その他の操作は白地・黒枠です。合計カードは角丸16dpと柔らかな影、商品カードは影を使わず薄い枠で区別します。主要ボタンはピル型、補助ボタン・入力欄は角丸8dpです。

合計金額は最大56spの細字、本文とボタンは16sp以上。見出しはAndroid標準sans-serif-light、日本語はOSのフォールバックを使用しています。独自フォントfigmaSansは同梱していません。英字の小さな注釈だけ12spの等幅です。スマホ用に要素を縦に配置し、一覧と長い入力画面をスクロール可能にしました。端末の文字サイズ設定によって表示は変わります。

## PayPay残高と購入後の残金

1. 合計欄の「PayPay残高・支払い記録」を開き、PayPayアプリで確認した残高を入力・貼り付けて保存します。0円も設定できます。
2. 商品を追加・削除・数量変更すると、「設定残高 − 買い物合計」で購入後の残金が自動更新されます。連続スキャン画面にも表示し、不足時は不足額を黒字の太字で表示します。
3. 会計後は「支払済みを記録…」で、実際に残高から支払った金額を確認・修正して記録します。アプリ内の残高を減らし、買い物一覧を空にします。実店舗の決済を実行する操作ではありません。

残高と設定日時は端末内に保存します。買い物リセットでは残高は減りません。「残高設定を解除」で未設定に戻せます。チャージや他の買い物の後は再設定してください。PayPayポイントは自動で加算しません。使うポイントを含める場合はその金額を含めて手動入力します。

**今回は手動の残高取り込みです。PayPayとの自動同期は未実装です。** PayPayの公式残高照会APIには別途申請とユーザー認可が必要なため、ログイン情報やAPI秘密鍵をこのAPKに入力する仕組みは作っていません。将来の正式連携では利用承認、認可フロー、秘密鍵を保管するサーバーが必要です。

公式資料：https://www.paypay.ne.jp/opa/doc/v1.0/direct_debit （Get user wallet balance）

## インストール

`KaimonoScan-v0.6.0-debug.apk` をスマホで開いてインストールしてください。v0.1.xと同じアプリID・署名で上書き更新できます。アンインストールする必要はありません。更新後も買い物一覧・手入力商品・Yahoo! Client IDは維持されます。

## 連続スキャン（v0.6.0）

1. ホームで **連続スキャンを開始** を押します。
2. バーコードを枠に合わせると、読み取り成功時に短く1回振動します。
3. 登録済み商品はそのまま合計・数量に反映され、カメラを閉じずに次の商品を読めます。
4. 未登録商品や価格が変わった商品は読み取りを一時停止し、従来の商品確認・検索画面を表示します。追加またはキャンセルして確認画面を閉じると、自動で次の読み取りに戻ります。
5. **一覧に戻る** または端末の戻る操作で、買い物一覧へ戻ります。

振動は「JANを読み取った」という通知です。未登録商品の価格がまだ確定していない場合、振動した段階では合計に追加されません。「追加しました」と点数・合計の表示を確認してください。

### 同じ商品を続けて読みたい場合

同じバーコードを映し続けても何度も数量が増えないようにしています。同じ商品をもう1個数える場合は、バーコードを枠から約1秒以上外してから再度映すか、**同じコードを再読取** を押してから読み取ってください。このボタン自体では数量は増えません。

異なるバーコードはそのまま順番に読み取れます。読み取りの間隔は最短約0.4秒です。複数のコードを同時に映した場合も、観測中の同じコードの重複を抑制します。

- 連続画面に点数と概算合計を表示します。
- ライトON/OFFボタンを付けました（フラッシュ対応端末）。
- 設定の **バーコード読取時に振動する** で、振動をOFFにできます。振動には端末のハードウェア・システム設定が影響します。
- カメラ権限が必要です。振動の通常権限を追加していますが、振動のための追加許可ダイアログはありません。
- 別アプリへ移動した間はカメラを停止します。
- 保存した手入力価格も、連続画面ではその保存値で自動追加します。価格改定時は一覧や設定から修正してください。

## セブンの商品を登録する（Yahoo!の設定不要）

1. ホームの **セブン登録** を押します。
2. 商品の8桁・13桁JAN番号を入力して「次へ」。
3. 短い商品名・ブランド名を入力し「商品名で検索」。例：ファイア。
4. 検索結果から正しい商品・容量を選びます。
5. 公式商品名・容量・1個分の価格・販売地域を確認し、手元の商品と一致することを確認するチェックを付けます。
6. 「登録して追加」を押すと、JANとページの対応と取得価格を端末内に保存します。
7. 次回から同じJANをスキャンすると、その商品のセブン掲載価格を使います。同じ買い物内なら数量が増えます。

Yahoo!検索で希望小売価格がない場合も、取得できた商品名を使ってセブン検索へ移れます。Yahoo!の認証エラーやClient ID未設定の場合もセブンで商品名検索できます。

### FIRE ONEDAY BLACKの例

- JAN：`4909411089368`
- 検索語：`ファイア`
- 選択する商品：キリン ファイアワンデイブラック 600ml
- 公式商品ページ： https://www.sej.co.jp/products/a/item/460833/

全商品名を長く入力すると見つからない場合があります。短いブランド名で検索し直してください。検索結果が0件の場合は、検索語の一部で1回だけ再検索する仕組みも入っています。

### URLから登録する

「セブン登録」の次画面で、公式商品詳細ページのURLを貼り付けて **URLから取得** を押します。検索で出てこない商品でも、対応形式の公式商品ページがあれば登録できます。

対応形式：`https://www.sej.co.jp/products/a/item/数字/`

公式ページを開いたブラウザでURLをコピーして貼り付けてください。URLは `www.sej.co.jp` の商品詳細ページだけを受け付け、別ドメインへの移動は追跡しません。

## 取得・保存・更新の仕様

- 初回のひも付けには必ず本人の確認が必要です。セブンのページにはJANが掲載されていないため、JANとの対応を機械だけで保証しません。
- 登録済み商品の取得価格は24時間キャッシュします。24時間以内はその値を自動で使います。
- キャッシュ期限後、次にスキャンした時にページを再取得します。アプリが閉じている間に定期巡回する方式ではありません。
- 同じ買い物一覧に既にある商品を再スキャンすると、その一覧の単価で数量だけ増やします。
- 行の **セブン価格を再取得・変更** → **今すぐ価格を再取得** から、期限前でも更新できます。
- 再取得で商品名・価格・販売地域が変わっていた場合は、再確認してから反映します。
- 更新に失敗した場合は、前の価格・取得日時を提示します。「保存価格を使う」を選んだ場合だけ追加します。
- 取得価格・出典URL・販売地域・確認日時は買い物一覧とともに端末内に保存します。
- 設定 → **セブンの登録商品を管理** から、再取得・リンク変更・削除ができます。
- ひも付けを削除しても、今回の買い物一覧の価格はそのままです。次回の買い物から商品を選び直せます。
- 既存の手入力保存商品がある場合は、その確認画面が優先します。セブンの商品を新しく登録すると、そのJANの保存手入力価格を置き換えてセブン掲載価格を使います。

## 価格と合計

**セブン公式掲載価格**と**メーカー希望小売価格**を区別して表示します。

セブン掲載の「税込182.52円」のような小数を保持し、数量を掛け、買い物全体を合計してから1円未満を切り捨てます。端数を1個ごとに捨てて合計する方式ではありません。手入力・Yahoo!希望小売価格の税抜換算は従来どおり1個ごとに切り捨てる概算です。

公式ページに書かれた販売地域・価格は、手元の店舗の販売価格・値引き・在庫を保証するものではありません。ページが古い場合や店舗・地域・税計算の違いで会計金額が変わるため、合計は目安として使ってください。

## Yahoo!商品検索（任意）

設定でYahoo! JAPANの **Client ID（アプリケーションID）** を登録します。Client Secretやパスワードは入力しません。

- Client ID取得案内： https://developer.yahoo.co.jp/start/
- 設定内の「入力中のIDを保存して接続テスト」で、接続を確認できます。
- JANが一致する検索結果から `priceLabel.fixedPrice` を取得します。通常販売価格・セール価格を希望小売価格として使いません。
- 希望小売価格が欠けていても、JANが一致する商品名をセブンの商品名検索に利用できます。
- HTTP401・403などの拒否はHTTP番号と判別できた理由を表示します。診断画面にはClient IDや応答の生データを出しません。

APIの利用には利用者自身の登録と利用条件への対応が必要です。すべての商品で取得できる保証はありません。

## データと権限

カメラ映像は端末内で解析し、画像をサーバーに送信しません。

- Yahoo!利用時：JANとClient IDをYahoo!の商品検索APIへ送信。
- セブン利用時：検索語と選択した商品ページのURLを公式サイトへ送信。ブラウザのログイン情報や7iDは使用しません。
- ひも付け・取得価格・買い物一覧・手入力商品・Client IDはアプリ専用領域に保存。OSバックアップ・端末移行は無効。
- データ削除やアンインストールで消えます。

アカウント登録、広告、アクセス解析、全商品を巡回するバックグラウンド機能は実装していません。操作した検索・商品ページを取得し、取得開始は1.2秒以上の間隔を空けます。公開サイトの仕様変更・掲載終了等により取得できなくなる場合があります。
